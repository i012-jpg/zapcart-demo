# ZapCart Demo

A responsive, front-end quick-commerce storefront demo built with plain HTML, CSS, and JavaScript.

## Features

- Product search and category browsing
- Promotional banners, product details, ratings, and recommendations
- Cart with quantity controls, minimum order amount, and item limits
- Demo coupon: `ZAP100` (₹100 off eligible orders)
- Mock phone/OTP login and checkout with UPI, card, and cash-on-delivery options
- Demo order status, profile, address, support, and notifications panels
- Responsive desktop and mobile layouts

## Run locally

Open `index.html` in a modern browser, or serve this folder with a local static web server.

## Demo notes

This project is a UI demo only. Login/OTP is not connected to an authentication service. Orders are not sent to a server, and no payment is processed.

## Files

- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — product data and demo interactions
